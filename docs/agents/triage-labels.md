# Rótulos de triagem

| Papel da skill | Rótulo no GitHub | Uso |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Aguardando avaliação. |
| `needs-info` | `needs-info` | Aguardando informações do autor. |
| `ready-for-agent` | `ready-for-agent` | Especificada para trabalho de agente. |
| `ready-for-human` | `ready-for-human` | Requer trabalho humano. |
| `wontfix` | `wontfix` | Não será implementada. |

Use a coluna "Rótulo no GitHub" ao aplicar ou remover um papel de triagem. O rótulo `wontfix` já existia antes desta configuração.
