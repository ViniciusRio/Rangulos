# Registros de decisões arquiteturais

Crie um ADR numerado (`0001-titulo.md`, `0002-titulo.md`, ...) quando uma decisão arquitetural tiver alternativas reais, for difícil de reverter e sua justificativa não estiver evidente no código. Registre contexto, decisão e motivo de forma breve.

Ainda não há decisão arquitetural confirmada nesta auditoria. As observações sobre o legado estão em `docs/research/legacy-audit.md`.
